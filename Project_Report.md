# Project Report: Personal UPI Usage and Financial Analyzer using LLMs

## 1. Overview
An AI-powered financial assistant that processes UPI transaction PDFs to analyze spending and provide insights using Google Gemini LLM.

## 2. Problem Statement
Extract and analyze UPI transaction data to generate actionable insights and recommendations.

## 3. Objectives
- Automate financial statement analysis.
- Identify income, expenses, and saving patterns.
- Provide AI-driven financial guidance.

## 4. Methodology
1. Extract PDF text using PyPDF2.  
2. Clean and structure data with Pandas.  
3. Analyze insights using Gemini LLM.  
4. Visualize using Streamlit dashboard.

## 5. Tools & Technologies
| Category | Tool/Library |
|-----------|--------------|
| Language | Python |
| UI Framework | Streamlit |
| PDF Parsing | PyPDF2 |
| AI Model | Google Gemini |
| Data Handling | Pandas |
| Visualization | Plotly |

## 6. Results
- Accurate extraction from transaction PDFs.
- LLM-generated insights and summaries.
- Easy-to-use dashboard.

## 7. Deployment
Deployable on Streamlit Cloud, Hugging Face Spaces, or Replit.

## 9. Impact
Empowers users with financial awareness and simplified data insights.
